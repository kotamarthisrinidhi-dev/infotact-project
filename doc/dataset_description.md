
# AtmoSync Dataset Description

## Overview

The AtmoSync dataset contains micro-climate weather observations from different locations.

## Dataset Size

The dataset contains 460 records and 11 columns.

## Geographical Information

The dataset contains:

- Location
- Latitude
- Longitude
- Elevation
- Area Profile

## Weather Information

The dataset contains:

- Maximum Temperature
- Minimum Temperature
- Rainfall
- Humidity
- Wind Speed

## Date Information

The date column represents the date associated with each weather observation.

## Analysis Purpose

The dataset will be used to study micro-climate variations, weather patterns, and relationships between different weather parameters.

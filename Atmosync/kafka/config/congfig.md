# AtmoSync Kafka Configuration

## Broker
localhost:9092

## Topic
atmosync_microclimate

## Purpose
The Kafka topic is used to stream micro-climate
weather records for downstream processing and storage.

## Data
Weather records contain:

- Date
- Location
- Latitude
- Longitude
- Elevation
- Area Profile
- Maximum Temperature
- Minimum Temperature
- Rainfall
- Humidity
- Wind Speed

# AtmoSync Submission Checklist

## Code

* [ ] Analysis scripts run successfully.
* [ ] Dashboard starts successfully.
* [ ] Charts and filters are verified.
* [ ] Errors found during testing are addressed or documented.

## Dataset

* [ ] Raw dataset is included.
* [ ] Cleaned dataset is available or its generation instructions are documented.
* [ ] Dataset size and columns are verified.

## Documentation

* [ ] README is complete.
* [ ] Final project report is reviewed.
* [ ] Dashboard user guide and troubleshooting guide are available.
* [ ] Analysis findings match actual outputs.

## GitHub

* [ ] Team contributions are included.
* [ ] Changes are pushed.
* [ ] Required pull requests are merged.
* [ ] Repository contains no unintended secrets or temporary files.

## Presentation

* [ ] PPT is ready.
* [ ] Dashboard demonstration is rehearsed.
* [ ] Screenshots are captured if needed.
* [ ] Team members are ready to explain their contributions.

## Final Status

Mark items complete only after verification. Record any remaining issues before submission.


# AtmoSync Temperature Analysis Summary

## Purpose

This document describes the temperature analysis performed on the AtmoSync micro-climate dataset.

## Temperature Parameters

The analysis focuses on:

- `temp_max_c`
- `temp_min_c`

## Basic Statistics

The following statistics are calculated:

- Average maximum temperature
- Average minimum temperature
- Minimum recorded temperature
- Maximum recorded temperature

## Temperature Range

Temperature range is calculated as:

```text
temperature_range_c = temp_max_c - temp_min_c
````

This helps understand the difference between maximum and minimum temperature for each observation.

## Location-wise Analysis

Average maximum and minimum temperatures are compared across different locations.

This helps identify variations in temperature between locations.

## Analysis Output

The temperature analysis provides:

* Overall temperature statistics
* Location-wise temperature comparison
* Temperature range
* Minimum and maximum temperature values

## Purpose of the Analysis

The results will be used for understanding micro-climate temperature variations and supporting further visualization and dashboard development.

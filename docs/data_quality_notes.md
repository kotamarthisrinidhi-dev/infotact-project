
AtmoSync Data Quality Notes

 Dataset Overview

The AtmoSync dataset contains micro-climate weather observations from different locations.

 Dataset Fields

The dataset includes information related to:

- Date
- Location
- Latitude
- Longitude
- Elevation
- Area Profile
- Maximum Temperature
- Minimum Temperature
- Rainfall
- Humidity
- Wind Speed

## Data Quality Checks

The following checks are considered during data preparation:

- Missing value check
- Duplicate record check
- Data type validation
- Date format validation
- Numerical value validation
- Outlier checking

## Weather Data Validation

Weather-related numerical columns should be checked for valid and consistent values before performing analysis.

Important weather fields include:

- temp_max_c
- temp_min_c
- rainfall_mm
- humidity_pct
- wind_speed_kmph

 Purpose

These data quality checks help prepare the AtmoSync dataset for further analysis and visualization.

# AtmoSync Data Dictionary

## Dataset Columns

| Column | Description |
|---|---|
| date | Date of the weather observation |
| location | Location where the observation was recorded |
| latitude | Latitude coordinate of the location |
| longitude | Longitude coordinate of the location |
| elevation_m | Elevation of the location in meters |
| area_profile | Profile or category describing the area |
| temp_max_c | Maximum temperature in degrees Celsius |
| temp_min_c | Minimum temperature in degrees Celsius |
| rainfall_mm | Rainfall amount in millimeters |
| humidity_pct | Relative humidity percentage |
| wind_speed_kmph | Wind speed in kilometers per hour |

# Dataset Information

## Dataset Name
Telangana Combined Weather Data

## Data Type
Weather and climate data

## Main Attributes
- District
- Mandal
- Date
- Rain (mm)
- Min Temp
- Max Temp
- Min Humidity
- Max Humidity

## Purpose
This dataset will be used for analyzing weather patterns, temperature, rainfall, and humidity across different districts and mandals of Telangana.

## Planned Analysis
- Temperature analysis
- Rainfall analysis
- Humidity analysis
- District-wise comparison
- Trend identification
- Data visualization

## Dataset Description

This dataset contains micro-climate weather observations for different locations.

The dataset includes geographical information such as latitude, longitude, and elevation, along with weather parameters such as maximum temperature, minimum temperature, rainfall, humidity, and wind speed.

## Purpose

The dataset will be used to analyze micro-climate patterns across different locations and identify relationships between weather and geographical characteristics.

## Planned Analysis

- Temperature analysis
- Rainfall analysis
- Humidity analysis
- Wind speed analysis
- Location-wise comparison
- Weather trend analysis
- Correlation analysis
- Data visualization

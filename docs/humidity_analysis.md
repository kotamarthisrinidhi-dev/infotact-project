
# AtmoSync Humidity Analysis

## Purpose

This document describes the humidity analysis planned for the AtmoSync micro-climate dataset.

## Humidity Field

The main humidity column is:

- `humidity_pct` – Relative humidity percentage

## 1. Average Humidity

Calculate the average humidity recorded in the dataset.

## 2. Minimum and Maximum Humidity

Identify:

- Minimum recorded humidity
- Maximum recorded humidity

## 3. Location-wise Humidity Analysis

Compare average humidity across different locations.

The analysis includes:

- Average humidity
- Minimum humidity
- Maximum humidity

## 4. Date-wise Humidity Analysis

Use the `date` field to study changes in humidity over time.

## 5. Temperature and Humidity

Study the relationship between temperature and humidity to understand possible micro-climate patterns.

## 6. Visualization

Humidity results can be represented using:

- Bar charts
- Line charts
- Histograms
- Box plots
- Scatter plots

## Expected Output

The analysis should provide:

- Average humidity
- Minimum humidity
- Maximum humidity
- Location-wise humidity comparison
- Date-wise humidity patterns
- Temperature and humidity relationship

## Final Objective

The humidity analysis will help understand humidity variations across locations and over time in the AtmoSync micro-climate dataset.

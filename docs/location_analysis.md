
# AtmoSync Location-wise Weather Analysis

## Purpose

This document describes the location-wise analysis planned for the AtmoSync micro-climate dataset.

## Location Field

The main location column is:

- `location`

## 1. Location Identification

Identify the different locations available in the AtmoSync dataset.

## 2. Temperature Comparison

Compare the following temperature parameters across locations:

- `temp_max_c`
- `temp_min_c`

Calculate average, minimum, and maximum values where required.

## 3. Rainfall Comparison

Compare rainfall across different locations using:

- `rainfall_mm`

The analysis can include average, minimum, maximum, and total rainfall.

## 4. Humidity Comparison

Compare humidity levels across locations using:

- `humidity_pct`

## 5. Wind Speed Comparison

Compare wind speed across locations using:

- `wind_speed_kmph`

## 6. Overall Weather Comparison

Compare major weather parameters across different locations:

- Temperature
- Rainfall
- Humidity
- Wind speed

## 7. Visualization

Location-wise results can be represented using:

- Bar charts
- Line charts
- Box plots
- Comparison charts

## Expected Output

The analysis should provide:

- Available locations
- Location-wise temperature comparison
- Location-wise rainfall comparison
- Location-wise humidity comparison
- Location-wise wind speed comparison
- Overall weather comparison

## Final Objective

The location-wise analysis will help identify differences in micro-climate conditions across the locations present in the Project
